# 제주 한 권

HTML·CSS·JavaScript로 만든 제주 1년살기 앱 무료 체험판입니다. 로그인·결제·유료 AI·서버 함수 없이 동작합니다. 산책 장소는 비짓제주에서 수동 수집한 정적 데이터로 제공합니다.

## 실행

이 폴더에서 PowerShell로 `powershell -ExecutionPolicy Bypass -File .\start.ps1`을 실행한 뒤 브라우저에서 http://localhost:8000 을 엽니다. 종료는 Ctrl+C입니다. 실행 정책 변경은 해당 프로세스에만 적용됩니다.

HTML을 직접 더블클릭하면 JSON을 읽지 못할 수 있으므로 로컬 서버를 사용하세요.

## 구성

- index.html: 화면 기본 구조와 팝업
- styles.css: 아이보리·숲색 반응형 디자인
- app.js: 메뉴, 필터, 상세 팝업, 기록 작성, 책 미리보기
- journal.js: 기록 작성·수정·검색·삭제, 임시 저장, JSON 백업·복원
- learning.js: 평생교육 탐색·필터·상세·관심 목록·배움 기록 연결
- learning-data.json: 공식 강좌·과목 정보와 구분된 프로그램 예시
- places.js: 실제 장소 검색·필터·출처·장소별 글쓰기
- places-data.json: 인증키를 제거한 실제 장소 24곳의 스냅샷
- sample-data.json: 글감·가상 산책·가상 배움·체험 기록
- assets/jeju-landscape.svg: 로컬 일러스트

기존 CSV는 기준연월·지역·방문 집계 또는 소비 집계 중심이며 자료별 지역 코드가 다릅니다. 원본 CSV·PDF는 수정하거나 직접 연결하지 않았습니다. 실제 강좌·운영시간·가격 정보는 생성하지 않았습니다. 배움 메뉴는 공식 자료와 예시 프로그램을 구분하며, 미확인 기관·비용·자격을 추정하지 않습니다. 체험 기록은 예시로 표시합니다.

## 확인

1. 다섯 메뉴를 이동하고 모바일 폭에서 가로 스크롤이 없는지 확인합니다.
2. 산책·배움의 필터, 상세 팝업과 Esc 닫기를 확인합니다.
3. 기록을 저장하고 새로고침 후에도 남는지 확인합니다.
4. 내 책에서 직접 쓴 기록만 보이는지 확인합니다.
5. 예시 데이터 표시와 데이터 안내를 확인합니다.

직접 작성한 글은 이 브라우저의 localStorage에만 저장됩니다. 브라우저 데이터 삭제 시 사라지고 다른 기기로 동기화되지 않습니다. 중요한 원고는 별도로 보관하세요. 예시 기록은 개인 기록 통계나 책 원고에 포함되지 않습니다. EPUB 생성·출간·강좌 신청은 이번 버전의 기능이 아닙니다.

## GitHub와 Vercel 배포

1. GitHub에서 새 저장소를 만들고 앱 소스를 올립니다. `.gitignore`는 허용된 앱 파일만 추적하도록 구성되어 있습니다. 브라우저에서 수동 업로드할 때는 이 규칙이 적용되지 않으므로 CSV·PDF·XLSX·HWP·tmp 폴더를 직접 업로드하지 마세요.
2. 저장소 루트에 index.html, styles.css, app.js, places.js, journal.js, learning.js, learning-data.json, places-data.json, sample-data.json, assets/jeju-landscape.svg, build.mjs, vercel.json이 있어야 합니다. README.md, start.ps1, .gitignore, .vercelignore, scripts 폴더도 함께 보관합니다.
3. Vercel에서 Add New → Project → 해당 GitHub 저장소를 Import합니다.
4. Framework Preset은 Other, Root Directory는 저장소 루트(./), Build Command는 node build.mjs, Output Directory는 dist입니다. vercel.json에 이 설정을 담았습니다. 별도 패키지 설치나 환경변수는 필요하지 않습니다.
5. Deploy 후 첫 화면, 산책·배움 카드, 기록 저장과 새로고침, 내 책을 확인합니다.

Node.js가 설치된 환경에서는 `node build.mjs`로 배포 파일만 dist에 생성할 수 있습니다. dist에는 웹앱용 10개 파일만 들어갑니다. 원본 데이터·인증키·갱신 스크립트는 서비스되지 않습니다. 빌드는 네트워크나 API 호출 없이 실행됩니다.

첫 배포 주소와 localhost는 서로 다른 저장 공간입니다. 로컬에서 쓴 기록은 배포 주소로 자동 이전되지 않습니다. 배포 후에도 기록은 접속한 브라우저에만 저장됩니다.

공식 설정 참고: https://vercel.com/docs/builds/configure-a-build

## 무료 체험 운영과 비짓제주 갱신

- 방문자는 정적 JSON을 받아 검색합니다. 방문·검색·기록 작성으로 비짓제주 API를 호출하지 않습니다.
- 데이터는 2026-11-06 비짓제주 API 59페이지(5,876건)를 한 차례 수집했습니다. 연결 확인 1회를 포함해 이번 작업의 API 요청은 60회입니다.
- 자연 관련 이름·태그 후보 527곳에서 소개를 검토해 상점·실내 테마파크·차도 중심 장소 등을 제외하고 24곳을 골랐습니다. scripts/place-selection.json에 선택한 ID를 보관합니다. 쉬운 경로·안전·연령별 적합성을 현장 검증한 목록이 아닙니다.
- 산책 카드에는 비짓제주 API의 대표 사진을 표시합니다. 목록은 썸네일, 상세는 원본 이미지 주소를 사용하고 지연 로딩합니다. 사진이 없거나 로딩에 실패하면 일러스트로 대체합니다. 카드와 상세 화면에 사진 출처를 표시합니다. 입장료와 시설 상태는 별도로 확인해야 합니다. 사진은 앱 화면 표시에만 사용하며 전자책에 포함하지 않습니다.
- 기존 장소 목록의 사진 주소만 갱신할 때는 `python scripts/update-places.py --key-file "인증키가_들어있는_로컬파일.txt" --photos-only`를 실행합니다. 현재 24곳에 대해 24번 조회하며, 사진 주소만 정적 JSON에 저장합니다. API 키·이미지 프록시·이미지 최적화 서버는 배포하지 않습니다. 이미지는 비짓제주 CDN에서 직접 불러옵니다.
- 수동 갱신은 Python 3으로 `python scripts/update-places.py --key-file "인증키가_들어있는_로컬파일.txt"`를 실행합니다. 기본 최대 60페이지, 순차 요청 사이 0.4초 대기, 자동 재시도 없음입니다. 키는 URL 요청에만 쓰며 로그·스냅샷·GitHub에는 저장하지 않습니다. HTTPS만 사용합니다.
- 갱신 실패·선정 ID 누락·페이지 한도 초과 시 기존 스냅샷을 보존합니다. 최신 JSON을 검토한 뒤 GitHub에 반영합니다. 자동 스케줄이나 Vercel 환경변수 설정은 필요 없습니다.
- Vercel의 Hobby(개인·비상업 용도) 무료 플랜과 기본 vercel.app 도메인을 유지합니다. 유료 업그레이드·유료 체험·추가 스토리지·AI 서비스는 신청하지 않습니다. 현재 계정 플랜은 이 코드로 확인하거나 강제할 수 없습니다. 무료 배포라고 해도 사업 목적의 서비스라면 Hobby 허용 여부를 별도로 검토해야 합니다.
- 공식 Hobby 안내상 한도 초과 시 대부분 해당 기능을 다시 쓸 수 있을 때까지 기다려야 합니다. 무료는 무제한 제공을 뜻하지 않습니다. https://vercel.com/docs/plans/hobby
- 소수 사용자에게 링크를 직접 공유하는 체험 운영을 전제로 검색엔진 noindex를 추가했습니다. noindex는 접근 제한이 아닙니다. 링크를 아는 다른 사람도 접속할 수 있습니다. 초대 전용 인증이나 비밀번호 보호는 이번 변경에서 추가하지 않았습니다.
- 기록은 이용자의 브라우저에만 저장됩니다. 운영자가 볼 수 없고 계정 간 공유되지 않지만, 같은 브라우저를 함께 쓰거나 브라우저 데이터를 삭제하면 영향을 받습니다.

## 산책 필터와 상세 정보

- 지역, 예상 소요시간(30분 이내 / 30분 초과~1시간 / 1시간 초과~2시간 / 2시간 초과), 걷기 난이도(쉬움 / 보통 / 어려움)를 테마·검색어와 함께 적용합니다. 시간과 난이도에 각각 ‘정보 확인 필요’ 선택지가 있습니다. 검색·필터 초기화로 모든 장소를 다시 봅니다.
- 현재 24곳의 관광지 소개·주소·사진은 비짓제주 정보이며, 보행 소요시간·난이도·경사·화장실·벤치·대중교통은 별도로 검증하지 않았습니다. 해당 정보는 모두 ‘정보 확인 필요’로 표시합니다. 미확인 장소는 쉬움·30분 이내 등 확인된 값이 필요한 결과에 포함하지 않습니다.
- places-data.json의 장소별 walkInfo에 검증된 보행 정보를 입력할 수 있습니다. durationMinutes는 양수 분 단위, difficulty는 쉬움·보통·어려움, slope/toilet/bench/transit는 설명, route는 시간·난이도의 기준 경로입니다. sourceUrl(HTTPS)과 checkedAt(YYYY-MM-DD)이 있어야 확인된 값으로 표시합니다. 수동 갱신 스크립트는 기존 walkInfo를 보존합니다.
- 방문량이나 사진·장소 이름으로 난이도, 실시간 혼잡도, 안전도를 추정하지 않습니다. 일반 관광지의 체류시간을 보행 코스 소요시간으로 바꾸어 쓰지 않습니다.
- 상세 팝업은 각 시설 정보를 개별 표시하며 ‘여기서 기록하기’로 장소별 글감과 산책 종류가 입력된 작성 창을 엽니다. 닫기 버튼과 Esc 키를 지원합니다. 사진이 없거나 로딩에 실패하면 일러스트로 대체합니다.

## 이 기기에 저장하는 내 기록

- 기록 종류(산책·독서·배움·일상), 날짜, 제목, 본문, 장소, 태그를 입력합니다. 장소와 태그는 선택 사항입니다. 제목은 100자, 본문은 20,000자, 장소는 200자, 태그는 20개 및 각 40자까지 지원합니다.
- 오늘의 글감은 본문에, 산책 상세의 ‘여기서 기록하기’는 장소명과 관련 질문을 작성 화면에 채웁니다. 기록 상세에서 수정·삭제할 수 있고, 삭제 전에 앱 확인창을 띄웁니다. 임시 글을 다른 글로 바꾸는 작업도 확인합니다.
- 기록 날짜 내림차순으로 정렬하고 같은 날짜에는 최근 수정 순서로 표시합니다. 제목·본문·장소·태그 검색과 종류별 필터를 함께 적용할 수 있습니다. 예시 기록은 별도 접힌 영역에 표시하며 검색·통계·백업·원고에서 제외합니다.
- 기존 저장 키 `jeju-one-book.entries.v1`을 유지합니다. 기존 한국어 날짜를 새 날짜 형식으로 읽으며 첫 변경 전에 기존 형식의 원본을 별도 로컬 키에 보관합니다. 읽을 수 없는 기존 데이터는 자동 삭제하거나 덮어쓰지 않습니다.
- 입력 후 약 0.4초에 브라우저 localStorage로 임시 저장하며, 창 닫기·페이지 이탈 시에도 남은 입력을 저장합니다. 임시 글은 브라우저별 한 편입니다. 다시 열면 이어 쓸 수 있고 정식 저장이 성공하면 임시 글을 정리합니다. 저장 상태와 실패 안내를 표시합니다.
- JSON 백업은 app/version/exportedAt/entries를 가진 파일이며 정식 저장한 기록 전체만 담습니다. 임시 글은 정식 저장 후 백업해야 합니다. JSON 파일은 최대 10MB, 10,000편까지 읽고 형식·길이·날짜를 검증한 뒤 추가·중복 건수를 보여줍니다. 기존 배열 형태의 백업도 읽을 수 있습니다.
- 가져오기는 기존 ID를 유지하고 중복 ID를 건너뜁니다. 수정본으로 기존 글을 덮어쓰지 않습니다. 잘못된 파일·저장 공간 부족·다른 창의 변경 감지 시 기존 기록을 보존합니다. 정상 반영은 한 번의 기록 저장으로 처리합니다.
- 사용자 글·장소·태그는 HTML을 이스케이프하거나 textContent로 표시합니다. JSON과 글은 서버나 외부 AI로 전송하지 않습니다. 실제 사용자 데이터는 GitHub에 포함되지 않습니다.
- 같은 기기라도 브라우저·사이트 주소가 다르면 저장 공간이 다릅니다. 브라우저 저장 데이터를 지우면 복원이 어려우므로 중요한 글은 JSON 백업을 따로 보관하세요. 백업 파일에는 본문이 포함됩니다.

## 배움 프로그램 탐색

- 주제는 글쓰기·독서·자연관찰·사진·공예·디지털 활용입니다. 지역(전체 지역·제주시·서귀포시)·주제·요일·수강료 구분·관심 목록과 검색어를 함께 적용합니다. 비용이 없는 자료를 무료로 추정하지 않습니다. 무료/유료 필터는 수강료 기준이며 재료비는 별도로 보여줍니다.
- 2026-11-08 공식 API를 확인했습니다. 첨부 HWP는 서귀포시 평생학습관의 무인증 JSON 서비스이고, 첨부 텍스트의 ODcloud namespace 15145035/v1은 교육청 직속기관 과목 목록입니다. 서로 다른 자료이며 후자는 개별 기관·비용·신청 기간·신청 자격을 제공하지 않습니다.
- 서귀포시 목록의 최신 3페이지 60건과 교육청 과목 775건에서 제목으로 주제를 분류했습니다. 명확한 아동·교원 대상 제목과 무관한 주제를 제외하고 실제 강좌·과목 20건을 연결했습니다. 이를 성인이나 장기체류자의 수강 자격 검증으로 해석하지 않습니다. 자연관찰은 이번 수집 범위에서 실제 강좌를 확인하지 못했습니다.
- 검색 및 오늘의 추천에는 실제 프로그램 중 접수 시작·종료 일시가 유효하고 현재 기간에 해당하며 기관 상태가 접수 중(COS002)인 항목만 표시합니다. 종료·예정·마감·취소·상태 미확인 및 예시를 제외합니다. 관심 목록에도 같은 조건을 적용하며 저장 ID는 삭제하지 않습니다. 자료가 없으면 빈 결과를 안내합니다.
